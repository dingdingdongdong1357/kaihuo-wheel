# 開伙轉盤

一個人住、一週開伙兩次的煮飯小工具。用轉盤抽這週要煮的菜，自動產生全聯購物清單，記錄每道菜煮了幾次，從新手練到拿手菜。

**打開：** https://dingdingdongdong1357.github.io/kaihuo-wheel/

## 加到手機主畫面
- **iPhone（Safari）**：打開網址 → 下方「分享」→「加入主畫面」
- **Android（Chrome）**：打開網址 → 右上「⋮」→「加到主畫面」或「安裝應用程式」

## 怎麼用
1. **抽菜**：第一輪抽這週要煮的菜，每道菜可以「換一道」、「調換位置」、「鎖定」。
2. **採買**：一週買一次，買了就勾。價格可以直接改成實際價格。
3. **開伙**：點菜名看做法和這次的挑戰。
4. **登記**：煮完按「煮好了」。煮 1 次是新手、3 次還算會做、5 次是拿手菜。
5. **每天吃什麼**：第二輪從這週的菜裡抽今天這一餐。
6. **結算**：一週結束勾一下煮了哪些菜，App 會記下冰箱還剩什麼。
7. **備份**：紀錄存在手機瀏覽器，偶爾到「設定」下載備份檔。

App 右上角的「?」有完整說明。
